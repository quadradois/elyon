# Admin Billing: documento arquivado

**Owner:** `platform-sre`
**Ultima validacao:** 2026-07-14

Nao existe servico Admin Billing no Compose nem container Admin na topologia de
producao atual. Portanto, este guia nao autoriza deploy, DNS ou troubleshooting
desse componente.

O conteudo antigo foi preservado em `DEPLOY_ADMIN_ARQUIVADO.md` apenas para
historico. Qualquer reintroducao do produto exige nova issue, threat model,
servico versionado no Compose, CI, observabilidade e runbook aprovados.

Para a operacao vigente, consulte o
[runbook operacional](../operacao/RUNBOOK_OPERACIONAL.md).

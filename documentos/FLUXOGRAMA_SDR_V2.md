## 📊 MÉTRICAS EM CADA ETAPA

```
ETAPA 1: INTERPRETAR
├─ Taxa de resposta: 25% → 30% (+20%)
└─ Tempo médio: 2h

ETAPA 2: QUALIFICAR
├─ Perguntas médias: 5 → 2 (-60%)
└─ Tempo médio: 10 min

ETAPA 3: PROPOSTA DE VALOR
├─ Taxa de interesse: 60% → 85% (+42%)
└─ Tempo médio: 5 min

ETAPA 4: OBJEÇÕES
├─ Taxa de conversão pós-objeção: 10% → 25% (+150%)
└─ Tempo médio: 15 min

ETAPA 5: FECHAMENTO
├─ Taxa de conversão: 15% → 35% (+133%)
└─ Tempo até envio de fotos: 2 dias → 4h (-83%)

ETAPA 6: CONFIRMAÇÃO
├─ Taxa de no-show: 35% → 15% (-57%)
└─ Confirmações completas: 60% → 95% (+58%)

ETAPA 7: NURTURING
├─ Taxa de reengajamento: 5% → 15% (+200%)
└─ Conversão de mornos: 3% → 8% (+167%)

ETAPA 8: MULTI-TOUCH
├─ Taxa de resposta no 2º contato: 10% → 15% (+50%)
└─ Taxa de opt-out: 12% → 8% (-33%)
```

## 🛠️ USO DE FERRAMENTAS POR ETAPA

```
ETAPA 1-3: Nenhuma ferramenta
├─ Foco em conversa e qualificação

ETAPA 4: Possíveis ferramentas
├─ buscar_imovel (se precisar dados do empreendimento)
└─ registrar_optout (se pedir para parar)

ETAPA 5: CRÍTICO - Sempre usar ferramentas
├─ converter_para_lead (quando aceitar anunciar)
└─ encaminhar_corretor (se lead QUENTE)

ETAPA 6: Confirmação obrigatória
├─ agendar_avaliacao (com TODOS os dados)
└─ Nunca deixar em aberto

ETAPA 7: Nurturing
├─ agendar_followup (data futura)
└─ qualificar_lead (temperatura MORNO)

ETAPA 8: Multi-touch
├─ Automático pelo sistema
└─ Não precisa usar tool manualmente
```

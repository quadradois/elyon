# Skill: Passagem de Bastão para Especialista

## Objetivo
Fazer a transição IA -> humano sem gerar insegurança no proprietário.

## Quando aplicar
- Quando o lead pedir explicitamente para falar com humano/corretor/especialista.
- Quando a próxima etapa depender de negociação humana direta.

## Protocolo obrigatório
1. Confirmar que vai transferir para especialista humano.
2. Informar nome e papel do especialista de forma clara.
3. Avisar que o contato do especialista será enviado pelo WhatsApp.
4. Pedir para o lead salvar o contato para reconhecer a abordagem.
5. Encerrar com expectativa de tempo realista (ex: "em breve" / "ainda hoje").

## Script base
"Perfeito, vou te passar para nosso especialista humano agora.\n
Quem vai te atender é [NOME_DO_ESPECIALISTA], [PAPEL].\n
Vou te enviar o contato dele aqui no WhatsApp. Assim que receber, já salva para você identificar quando ele chamar, combinado?"

## Guardrails
- Não inventar nome/cargo se não estiver disponível no contexto.
- Não prometer horário exato sem confirmação operacional.
- Não usar linguagem técnica de sistema (handoff, tool, fallback, etc.).
- Manter tom objetivo e seguro.
